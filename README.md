# 至尊终端 — McReeve 科研平台移动端

> 课题组文献库、科研路线、PDF 阅读与个人阅读笔记，装进口袋。

## 简介

**至尊终端**（Supreme Terminal）是 [McReeve 科研平台](https://mcreeve.cn/lit) 的 Android 客户端。它以极轻量的方式（~315 KB）把整个科研平台搬到手机上——课题组共享的参照文献库、AI 驱动的科研雷达、结构化的科研路线、以及完全私有的个人阅读版本，随时随地可用。

## 平台能力

### 文献库 — 组内共享 + 个人私有

McReeve 按课题组组织文献：组长维护共享的**参照文献库**，按研究方向分成子库；组员只读参与。与此同时，每篇文献你都可以建立**属于自己的阅读版本**——个人高亮、词汇、摘录和笔记完全私有，只有你自己可见。

参照文献库和个人文献库各自独立，互不干扰。你可以把组内的好文献收进个人总库，建立子库并持续积累自己的阅读笔记。

### 科研雷达 — AI 每日推荐

科研雷达是平台的 AI 发现引擎。它根据课题组当前维护的科研路线，每天自动筛选并推荐可能相关的最新文献。每条推荐包含：

- 中文标题与相关性评分（0–100）
- "为什么值得关注"的简要分析
- 与当前科研路线的联系说明
- 方法注释、主要结果、局限性与谨慎解读

组员看到好文献可以"推荐给组长"，组长决定是否采纳纳入组内参照库。你也可以对推荐内容做反馈（有帮助 / 不感兴趣），帮助雷达越来越懂你的方向。

### 科研路线 — 结构化研究脉络

科研路线按课题组隔离，记录从"问题"到"任务"再到"文献证据"的完整研究脉络。每条路线独立维护，帮助课题组把散落的文献串成有逻辑的研究叙事。

### PDF 阅读与标注

内置 PDF 阅读器，支持四类标注：高亮、词汇、摘录和笔记。在参照版上查看组内维护的知识，在个人版上积累自己的阅读痕迹。标注按文献维度组织，支持 `/annotations/:bookId` 集中管理。

### 课题组协作

- **组长**：增删改文献库、维护科研路线、审批组员的雷达推荐
- **组员**：只读参与共享内容，拥有完全私有的个人文献空间
- **服务器管理员**：可只读查看所有课题组，管理注册邀请码

## 技术特点

- **极致轻量** — APK 仅约 315 KB，核心功能由云端提供，App 始终保持轻巧
- **原生体验** — 基于 WebView 封装，保留原生文件选择、沉浸式状态栏、应用内自更新等 Android 特性
- **支持 Android 7.0+**
- **内置自更新** — 启动即检测版本，支持静默下载与安装

## 安装

1. 从 [Releases](../../releases) 页面下载最新的 APK 文件
2. 在手机上允许「安装未知来源应用」
3. 安装 APK，打开即可使用

App 内置自动更新，首次打开后会自动检测并提示升级到最新版本。

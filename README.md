# McReeve 科研平台

> 课题组文献库、科研路线、PDF 阅读与个人阅读笔记。

## 简介

McReeve 是一个按课题组组织的科研文献与路线管理平台。核心理念很简单：**组内共享参照，个人版本私有**。

组长维护共享的参照文献库和研究路线，组员只读参与；与此同时，每篇文献你都可以建立属于自己的阅读版本——高亮、词汇、摘录和笔记完全私有。

平台提供 **Web 版**和 **Android 客户端（至尊终端）** 两种使用方式。

- Web 版：[https://mcreeve.cn/lit](https://mcreeve.cn/lit)
- Android 版：从 [Releases](../../releases) 下载 APK 安装

## 功能模块

### 文献库

文献库分两层：

- **参照文献库**（组内共享）：按研究方向分成子库，由组长维护，组员只读查看。每篇文献上积累的词汇、摘录、笔记对全组可见。
- **我的文献**（完全私有）：个人文献空间，可以建立子库，收录自己关心的文献，积累私有的阅读标注。

你可以把组内参照库里的好文献收进个人总库，建立自己的阅读版本，参照与个人互不干扰。

### 科研雷达

科研雷达是平台的 AI 发现引擎。它根据课题组当前维护的科研路线，每天自动筛选并推荐可能相关的最新文献。每条推荐包含：

- 中文标题与相关性评分（0–100）
- "为什么值得关注"的简要分析
- 与当前科研路线的联系说明
- 方法注释、主要结果、局限性与谨慎解读

组员看到好文献可以"推荐给组长"，组长决定是否采纳纳入组内参照库。你也可以对推荐内容做反馈（有帮助 / 不感兴趣），让雷达越来越精准。

### 科研路线

科研路线按课题组隔离，记录从"问题"到"任务"再到"文献证据"的完整研究脉络。每条路线独立维护，帮助课题组把散落的文献串成有逻辑的研究叙事。科研雷达的推荐也是基于当前路线来匹配相关性的。

### PDF 阅读与标注

内置 PDF 阅读器，支持四类标注：高亮、词汇、摘录和笔记。在参照版上查看组内维护的知识，在个人版上积累自己的阅读痕迹。标注按文献维度集中管理。

### 课题组协作

- **组长**：增删改文献库和参照文献、维护科研路线、审批组员的雷达推荐
- **组员**：只读参与共享内容，拥有完全私有的个人文献空间
- **服务器管理员**：可只读查看所有课题组，管理用户注册与邀请码

## 使用方式

### Web 版

直接在浏览器访问 [https://mcreeve.cn/lit](https://mcreeve.cn/lit)，注册并加入课题组后即可使用全部功能。

### Android 客户端（至尊终端）

1. 从 [Releases](../../releases) 页面下载最新 APK
2. 在手机上允许「安装未知来源应用」
3. 安装后打开，使用与 Web 版相同的账号登录

客户端内置自动更新，启动时会检测并提示升级到最新版本。APK 仅约 315 KB，核心功能由云端提供，客户端始终保持轻量。

## 注册与加入

注册需要管理员提供的邀请码。加入课题组后可以阅读共享参照文献与科研路线，也可以建立自己的个人文献版本。

## 技术栈

- 前端：React SPA
- 客户端：Android WebView 封装（~315 KB），保留原生文件选择、沉浸式状态栏、应用内自更新等特性
- 支持 Android 7.0+

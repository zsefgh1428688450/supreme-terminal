# McReeve 科研平台

> 课题组文献库、科研路线、科研资讯与个人阅读笔记 — Web 与移动端统一体验。

## 简介

McReeve 是一个面向科研团队的文献与路线管理平台，围绕**课题组**组织一切：组长维护共享的参照文献库和科研路线，组员只读参与；每篇文献你还可以建立属于自己的阅读版本，个人标注完全私有。

平台提供 **Web 版**和 **Android 客户端**两种使用方式，数据云端同步，多端体验一致。

## 核心功能

### 课题组管理

每个课题组是一个独立空间，拥有自己的文献库和科研路线。角色分工清晰：

- **组长**：维护参照文献库、规划科研路线、审批组员推荐
- **组员**：阅读共享内容，拥有完全私有的个人文献空间
- **服务器管理员**：只读查看所有课题组，管理用户注册与邀请码

组内内容仅本组成员可见，不同课题组之间完全隔离。

### 科研路线规划与推进

科研路线是平台的核心脉络，记录从"问题"到"任务"再到"文献证据"的完整研究路径。每条路线独立维护，帮助课题组把散落的文献和想法串成有逻辑的研究叙事，追踪研究方向的实际推进状态。

科研雷达的 AI 推荐也是基于当前路线来匹配相关性——路线越清晰，推荐越精准。

### 文献管理

文献分两层管理，互不干扰：

- **参照文献库**（组内共享）：按研究方向分成子库，由组长维护。每篇文献上积累的词汇、摘录、笔记对全组可见。
- **我的文献**（完全私有）：个人文献空间，可以建立子库，收录自己关心的文献，积累私有的阅读标注。

组内的好文献可以一键收进个人总库，建立自己的阅读版本。

### 科研资讯获取（科研雷达）

科研雷达是平台的 AI 发现引擎，根据课题组当前的科研路线，每天自动筛选并推荐可能相关的最新文献。每条推荐包含：

- 中文标题与相关性评分（0–100）
- "为什么值得关注"的分析
- 与当前科研路线的联系说明
- 方法注释、主要结果、局限性与谨慎解读

组员可以"推荐给组长"，组长决定是否采纳纳入组内参照库。你也可以标记"有帮助"或"不感兴趣"，帮助雷达持续优化。

### PDF 阅读与标注

内置 PDF 阅读器，支持四类标注：高亮、词汇、摘录和笔记。在参照版上查看组内维护的知识，在个人版上积累自己的阅读痕迹。

## 使用方式

### Web 版

直接在浏览器访问 [https://mcreeve.cn/lit](https://mcreeve.cn/lit)，注册并加入课题组后即可使用全部功能。

### Android 客户端（至尊终端）

1. 从 [Releases](../../releases) 下载最新 APK（~315 KB）
2. 允许「安装未知来源应用」后安装
3. 使用与 Web 版相同的账号登录

客户端内置自动更新，核心功能由云端提供，始终保持轻量。支持 Android 7.0+。

## 注册与加入

注册需要管理员提供的邀请码。加入课题组后即可访问共享文献与科研路线，同时拥有自己的私有空间。

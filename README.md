# 至尊终端 — 科研论文阅读助手

> 轻量级 Android 客户端，让论文阅读不再在 PDF 阅读器、翻译器和笔记工具之间来回切换。

## 简介

**至尊终端**（Supreme Terminal）是 [McReeve 科研平台](https://mcreeve.cn/book) 的 Android 客户端，专为科研工作者和研究生打造的论文阅读辅助工具。

它将 AI 辅助阅读、文献管理和标注功能整合到一个沉浸式阅读体验中，帮助你在阅读英文论文时减少工具切换的心智负担。

## 核心功能

- **AI 辅助阅读与翻译** — 遇到不理解的段落或术语，AI 即时解释和翻译，无需离开阅读界面
- **文献管理与标注** — 统一管理你的论文库，支持高亮、批注和笔记，阅读痕迹一目了然
- **沉浸式阅读** — 专为长文阅读优化的全屏模式，减少干扰，专注内容
- **本地文档支持** — 直接打开设备上的 PDF 文件，支持多文件批量导入
- **自动更新** — 内置版本检测与静默更新，始终保持最佳体验

## 技术特点

- **极致轻量** — APK 仅约 315 KB，不占存储空间
- **云端驱动** — 核心阅读与 AI 能力由 McReeve 云端提供，App 始终保持轻巧
- **原生体验** — 基于 WebView 封装，同时保留原生文件选择、沉浸式状态栏等 Android 特性
- **支持 Android 7.0+**

## 安装

1. 从 [Releases](../../releases) 页面下载最新的 APK 文件
2. 在手机上允许「安装未知来源应用」
3. 安装 APK，打开即可使用

> App 内置自动更新功能，首次打开后会自动检测并提示升级到最新版本。
